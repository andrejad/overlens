# Security

Please report a vulnerability privately, not in a public issue: use **Report a vulnerability** on the repository's
Security tab (GitHub private vulnerability reporting). Say what you found, how to reproduce it, and which version
(`roadmap -version`) it affects. You'll get an answer as soon as possible, and a fix is released before the details are
made public.

Overlens is meant to run inside a company network (VPN). Its trial downloads start with the admin login `admin` /
`admin`; change that password on the first login, and do not expose an installation to the internet before you have.
